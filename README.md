# Livewire Network Solutions

Static marketing site for Livewire Network Solutions — camera and network security for homes and small businesses in Northeast Indiana.

## Files

```
index.html       — main page
thanks.html      — post-submission confirmation
styles.css       — all styling
script.js        — mobile menu + footer year
netlify.toml     — Netlify config
robots.txt       — search engine directives
sitemap.xml      — sitemap
```

## Deploy

1. Unzip files at the root of your GitHub repo
2. Push to main — Netlify auto-deploys
3. Build command: blank. Publish dir: `.` (handled by netlify.toml)

## Contact form

Uses Netlify Forms (`data-netlify="true"`). Submissions appear in Netlify dashboard → Forms.
